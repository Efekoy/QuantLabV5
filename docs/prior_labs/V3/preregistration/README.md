# Pre-registration

Before discovery starts, write here, then hash each file and record its SHA-256 in the discovery freeze note:

1. `HYPOTHESES.md` -- the behaviour classes to test and why they should work.
2. `SEARCH_SPACE.md` -- the exact grids (small), exits, directions and windows.
3. `DISCOVERY_SELECTION_RULE.md` -- how candidates enter DISCOVERY_FREEZE.json.
4. `CONFIRMATION_RULE.md` -- how the FINAL cohort is chosen from confirmation (2019-2022) results.
5. `HOLDOUT_EVALUATION.md` -- what 2023-2025 and 2026 will be judged on, fixed BEFORE they open.

Rules can be added, never edited after the stage they govern has opened.
